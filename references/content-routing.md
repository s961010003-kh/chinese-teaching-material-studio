# Content routing

## Literature and classical text

Use Scene to establish setting, actors, action, point of view, mood, and concrete evidence. Use Framework to reveal chronology, spatial movement, question/answer structure, contrast, imagery, rhetoric, theme, or “surface meaning → implied meaning.”

Recommended learning movement: enter the scene → read/mark the text → explain concrete meaning → connect evidence → infer emotion or argument → transfer/compare.

Do not let atmospheric imagery replace textual evidence. Label historical imagery as teaching reconstruction rather than documentary fact.

## Grammar, sentence patterns, rhetoric, and abstract concepts

Use Scene only to make an event or communicative intention observable. Keep exact analysis in Framework.

Recommended learning movement: observe a situation → say what happened → identify a word/constituent's job → name the category → test with a contrast or counterexample → apply to a new sentence.

Prefer functional questions over memorized labels, for example:

- word class: naming / acting / describing / limiting / substituting / counting / connecting;
- sentence pattern: doing / existing-having / identifying / describing state;
- rhetoric: literal event → linguistic choice → reader effect.

Test category decisions in context. Include at least one plausible misconception and one counterexample. Avoid classification by a single keyword when function can change.

## Reading comprehension and argument

Use evidence maps, cause-effect chains, claim-evidence-reasoning, point-of-view comparison, paragraph-function maps, and progressive disclosure. Scene is optional unless a concrete event materially improves comprehension.

## Scope calibration

For review lessons, prioritize retrieval, misconception diagnosis, transfer, and concise explanation. Do not reproduce the full source sequence merely because it exists.
