# Shared teaching unit model

Create this model before producing any deliverable. Markdown or JSON is acceptable. Keep “unknown” values explicit rather than inventing them.

## Required fields

- `title`, `subject`, `audience`, `use_case`, `lesson_minutes`
- `source_files` and relevant page/section identifiers
- `source_facts`: text, definitions, annotations, examples, interpretation, and assessment material supported by the source
- `prior_knowledge`
- `learning_objectives`: observable learner outcomes
- `core_question`
- `key_concepts`: term, learner-friendly explanation, evidence/example
- `misconceptions`: likely error, why it occurs, counterexample, correction
- `learning_sequence`: hook, observation, naming, guided analysis, transfer, assessment
- `scene_needs`: concrete situations that make meaning visible
- `framework_needs`: exact structures, classifications, timelines, comparisons, or reasoning paths
- `assessment`: prompt, expected evidence, answer/rubric
- `deliverables`

## Evidence discipline

Distinguish:

- source-supported fact;
- widely established background checked from an authoritative source when necessary;
- instructional inference;
- generated historical or everyday reconstruction;
- predicted student difficulty;
- actual classroom observation supplied by the teacher.

Do not convert predictions into reported classroom results.
